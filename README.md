# 홍익인간

> **전자출결 화면에 빠르게 도달할 수 있도록 만든 홍익대학교 학생용 비공식 오픈소스 앱**

홍익인간은 출결을 핵심으로, 식당 메뉴와 열람실 좌석 현황까지 한곳에서 확인하도록 돕는 학생 편의 서비스입니다. 대규모 강의실처럼 네트워크가 혼잡한 환경에서도 필요한 출결 흐름에 빠르게 도달하는 것을 목표로 합니다.

홍익인간은 홍익대학교와 신한은행이 제공하는 공식 서비스가 아닌, 학생을 위해 만든 오픈소스 프로젝트입니다.

## 바로 사용하기

| 사용하는 기기 | 권장 방식 | 사용 방법                                                                                                             |
| --- | --- |-------------------------------------------------------------------------------------------------------------------|
| Android | 네이티브 앱 또는 PWA | [GitHub Releases](https://github.com/LeeHeoJae/Hongik_Ingan/releases)에서 APK를 설치하거나, [웹 버전](https://hongik-ingan.vercel.app)에서 PWA를 설치합니다. |
| iPhone / iPad | 웹 또는 PWA | [웹 버전](https://hongik-ingan.vercel.app)의 앱 안내에서 설치 방법을 확인하거나, Safari의 **공유 → 홈 화면에 추가**를 선택합니다.                   |
| Windows | 웹 또는 PWA | [웹 버전](https://hongik-ingan.vercel.app)의 앱 안내에서 **앱 설치**를 선택합니다. Chrome과 Edge를 권장합니다.                             |
| Mac | 웹 또는 PWA | [웹 버전](https://hongik-ingan.vercel.app)에 접속한 뒤 Safari의 **파일 → Dock에 추가**를 선택합니다.|

> Android에서는 네이티브 앱과 PWA를 모두 사용할 수 있습니다.

> PWA를 설치하면 홈 화면, Dock 또는 Windows 앱 목록에서 일반 앱처럼 실행할 수 있습니다. 브라우저와 운영체제에 따라 메뉴 이름과 설치 방식이 다를 수 있습니다.

> 웹 버전(PWA)은 **처음 실행할 때** 앱 화면에 필요한 파일을 내려받으므로 로딩 시간이 더 걸릴 수 있습니다. 이후 실행에서는 이미 내려받은 리소스를 활용하므로 더 빠르게 열립니다.

## 핵심 기능

| 상황 | 제공 기능 |
| --- | --- |
| 수업 직전 | 현재 출석 가능한 수업 확인 및 출결 |
| 식사 전 | 교내 식당 메뉴 확인 |
| 공부할 자리 찾기 | 열람실별 잔여 좌석 현황 확인 |
| 앱 설치가 어려울 때 | PWA 웹 버전 사용 |

## 사용 전 알아둘 점

- 학교 시스템 변경, 세션 만료, 위치 정보, 네트워크 상태에 따라 출결이 실패할 수 있습니다.
- 출결이 정상적으로 처리되었는지는 반드시 학교 공식 시스템에서 확인하세요.
- 이 앱은 홍익대학교와 신한은행의 공식 서비스가 아닙니다.
- 앱 사용으로 발생할 수 있는 계정 정지, 데이터 유실, 출결 누락 등에 대해 개발자는 책임을 지지 않습니다.

## 왜 만들었나요?

헤이영 캠퍼스 앱은 다양한 기능을 제공하는 만큼 처음 화면이 나타날 때까지 시간이 걸립니다. 특히 대규모 강의실처럼 많은 사용자가 같은 네트워크에 동시에 접속하면 이 대기 시간이 더 길어질 수 있습니다. 홍익인간은 학생이 매일 사용하는 출결 흐름을 짧고 단순하게 만드는 데 집중했습니다.

학생 식당 메뉴와 열람실 좌석 현황도 한 곳에서 확인할 수 있도록 모았습니다.

학교 공식 서비스를 대체하기보다, 학생이 반복해서 수행하는 교내 업무를 더 편하게 만드는 것을 목표로 합니다.

## 출결 성능 측정

이번 측정에서는 홍익인간 앱이 모든 조건에서 PWA보다 빠르게 전자출결 화면에 도달했습니다.

**가장 혼잡한 조건의 결과**

가장 혼잡한 환경에서 전자출결 화면까지 걸린 시간은 **홍익인간 앱 3.58초 → PWA 5.92초 → 헤이영 캠퍼스 13.50초**였습니다.

이 조건에서 앱은 PWA보다 **2.34초 빠르고(39.5% 단축)**, 헤이영 캠퍼스보다 **9.92초 빠릅니다(73.5% 단축)**. 상세 조건과 측정 방법은 아래에서 확인할 수 있습니다.

헤이영 캠퍼스, 홍익인간 앱, 홍익인간 웹(PWA)을 대상으로 앱 아이콘을 누른 시점부터 지정한 전자출결 화면이 처음 안정적으로 나타나는 시점까지의 시간을 비교했습니다. 측정은 [`6435342`](https://github.com/LeeHeoJae/Hongik_Ingan/commit/64353428eb30afb691c1e8b941e5b822d6184d45) 커밋 기준의 앱과 웹 빌드에서 진행했습니다. 갤럭시 S25+를 갤럭시북5 프로의 모바일 핫스팟에 연결하고, Clumsy Hotspot으로 네트워크 프로필을 설정했습니다.

| 네트워크 조건 | 홍익인간 앱 | 홍익인간 웹 (PWA) | 헤이영 캠퍼스 |
| --- | ---: |-------------:| ---: |

| 약간 혼잡 (상향 및 하향 10 Mbps, 지연 80 ms) | **2.17초** |        5.85초 | 6.97초 |
| 혼잡 (상향 및 하향 2.4 Mbps, 지연 150 ms) | **3.58초** |        5.92초 | 13.50초 |

앱을 기준으로 비교하면 다음과 같습니다.

- 정상: PWA보다 **0.77초(23.5%)**, 헤이영 캠퍼스보다 **1.64초(39.6%)** 빨랐습니다.
- 약간 혼잡: PWA보다 **3.68초(62.9%)**, 헤이영 캠퍼스보다 **4.80초(68.9%)** 빨랐습니다.
- 혼잡: PWA보다 **2.34초(39.5%)**, 헤이영 캠퍼스보다 **9.92초(73.5%)** 빨랐습니다.

세 조건 모두 전자출결 화면에 도달한 순서는 **홍익인간 앱 → 홍익인간 PWA → 헤이영 캠퍼스**였습니다.

## 인증 정보 처리

| 구분 | 네이티브 앱 | 웹 / PWA |
| --- | --- | --- |
| 인증 요청 | 사용자 기기에서 처리 | 브라우저에서 Vercel 서버리스 프록시를 경유 |
| 프록시 역할 | 사용하지 않음 | 브라우저가 직접 통신하기 어려운 학교 서버와의 요청 및 인증 쿠키 전달을 중계 |
| 인증 정보 저장 | 사용자 기기의 보안 저장소와 쿠키 저장소에서 처리 | 브라우저 측에서 처리하며, 프록시에서 별도로 저장하지 않음 |

웹 버전은 브라우저 보안 제약(CORS) 때문에 일부 인증 요청이 프록시를 일시적으로 경유합니다. 프록시는 Node.js 기반의 Vercel Serverless Function으로 구성되어 있습니다.
