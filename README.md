# 홍익인간

> **수업 직전에도 빠르게 출결할 수 있도록 만든 홍익대학교 학생용 비공식 오픈소스 앱**

홍익인간은 출결을 핵심으로, 식당 메뉴와 열람실 좌석 현황까지 한곳에서 확인하도록 돕는 학생 편의 서비스입니다. 네트워크가 제한된 환경에서도 필요한 출결 흐름에 빠르게 도달하는 것을 목표로 합니다.

## 바로 사용하기

| 사용하는 기기 | 권장 방식 | 사용 방법 |
| --- | --- | --- |
| Android | 네이티브 앱 | [GitHub Releases](https://github.com/LeeHeoJae/Hongik_Ingan/releases)에서 APK를 내려받아 설치합니다. |
| iPhone / iPad | 웹 또는 PWA | [hongik-ingan.vercel.app](https://hongik-ingan.vercel.app)에 접속한 뒤 Safari의 **공유 → 홈 화면에 추가**를 선택합니다. |
| PC 및 그 외 기기 | 웹 | [hongik-ingan.vercel.app](https://hongik-ingan.vercel.app)에 접속해 브라우저에서 바로 사용합니다. |

> Android에서는 네이티브 앱을 지원합니다. iOS와 그 외 플랫폼에서는 웹 또는 PWA로 사용할 수 있습니다. PWA는 한 번 열어 둔 뒤 홈 화면에 설치하면 일반 앱처럼 실행할 수 있습니다.

> 웹/PWA는 **처음 실행할 때** 앱 화면에 필요한 파일을 내려받으므로 로딩 시간이 더 걸릴 수 있습니다. 이후 실행에서는 이미 내려받은 리소스를 활용하므로 더 빠르게 열립니다.

## 핵심 기능

| 상황 | 제공 기능 |
| --- | --- |
| 수업 직전 | 현재 출석 가능한 수업 확인 및 출결 |
| 식사 전 | 교내 식당 메뉴 확인 |
| 공부할 자리 찾기 | 열람실별 잔여 좌석 현황 확인 |
| 앱 설치가 어려울 때 | PWA 웹 버전 사용 |

## 왜 만들었나요?

수업 시작 전에는 짧은 시간 안에 출결을 완료해야 합니다. 기존 서비스에서 로그인 후 필요한 메뉴를 찾고 페이지가 로드되기를 기다리는 과정이 길어질 수 있어, 홍익인간은 학생이 실제로 자주 사용하는 출결 흐름을 짧고 단순하게 만드는 데 집중했습니다.

학교 공식 서비스를 대체하기보다, 학생의 반복적인 교내 업무를 더 편하게 만드는 것을 목표로 합니다.

## 출결 성능 테스트

헤이영 캠퍼스, 홍익인간 앱, 홍익인간 웹(PWA)을 대상으로 앱 아이콘을 누른 시점부터 지정한 전자출결 화면이 처음 안정적으로 나타나는 시점까지의 시간을 비교했습니다. 측정은 [`6435342`](https://github.com/LeeHeoJae/Hongik_Ingan/commit/64353428eb30afb691c1e8b941e5b822d6184d45) 커밋 기준의 앱과 웹 빌드에서 진행했습니다. 갤럭시 S25+를 갤럭시북5 프로의 모바일 핫스팟에 연결하고, Clumsy Hotspot으로 네트워크 프로필을 설정했습니다.

| 네트워크 조건 | 홍익인간 앱 | 홍익인간 웹 | 헤이영 캠퍼스 |
| --- | ---: | ---: | ---: |
| 정상 (네트워크 제한 없이 쾌적한 환경) | **2.50초** | 3.27초 | 4.14초 |
| 약간 혼잡 (상향 및 하향 10 Mbps, 지연 80 ms) | **2.17초** | 5.85초 | 6.97초 |
| 혼잡 (상향 및 하향 2.4 Mbps, 지연 150 ms) | **3.58초** | 5.92초 | 13.50초 |

- **홍익인간 앱:** 헤이영 캠퍼스보다 정상에서 **39.6%**, 약간 혼잡에서 **68.9%**, 혼잡에서 **73.5%** 짧았습니다.
- **홍익인간 웹:** 헤이영 캠퍼스보다 정상에서 **21.0%**, 약간 혼잡에서 **16.1%**, 혼잡에서 **56.1%** 짧았습니다.

> 조건별 9~11회로 진행한 탐색적 측정 결과입니다. 프레임 분석 간격은 0.25초이며, 판독 오차는 약 ±0.5초입니다. 기기, 계정, 학교 서버 상태, 측정 시점에 따라 실제 결과는 달라질 수 있습니다.

## 인증 정보 처리 및 출결 전 확인 사항

- 이 앱은 홍익대학교와 신한은행의 공식 서비스가 아닙니다.
- 네이티브 앱의 인증 정보는 사용자 기기에서 처리합니다.
- 웹 버전은 브라우저 보안 제약으로 인해 인증 요청이 Vercel 서버리스 프록시를 일시적으로 경유합니다.
- 프록시는 Node.js 기반의 Vercel Serverless Function으로 구성되어, 브라우저가 직접 요청하기 어려운 학교 서버와의 통신 및 인증 쿠키 전달을 중계합니다. 인증 정보는 프록시에서 별도로 저장하지 않습니다.
- 학교 시스템 변경, 세션 만료, 위치 정보, 네트워크 상태 등에 따라 출결이 실패할 수 있습니다. 출결 결과는 반드시 학교 공식 시스템에서 확인하세요.
- 이 앱 사용으로 발생할 수 있는 계정 정지, 데이터 유실, 출결 누락 등 문제에 대해 개발자는 책임을 지지 않습니다.
